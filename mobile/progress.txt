## 学习笔记

### 设计风格
- 使用"温暖守护"设计风格（晨光橙 #FF8A65 + 生命绿 #66BB6A）
- 遵循 UI/UX Pro Max 优化标准
- 所有圆角 8-32px
- 所有间距 16-64px
- 所有阴影使用橙色

### 技术实现
- 使用 Expo 54 + React Native
- 使用 Expo Router 进行路由管理
- 使用 React Context 进行状态管理
- 使用 Pressable 替代 TouchableOpacity
- 添加 hitSlop 扩展触摸区域
- 添加无障碍属性
- 使用 FlatList 优化长列表性能
- 使用 Mock 数据代替真实 API
