# 起了吗 App - 设计风格文档
## 温暖守护 · 晨光橙 + 生命绿

---

## 1. 设计理念

### 产品定位
"起了吗App" 是面向独居人群的紧急医疗服务应用，不是冰冷的医疗工具，而是温暖的守护者。

### 意象锚点
> **清晨 7 点，阳光透过米白色纱帘洒进房间，光束中漂浮着微尘。床头的心率监测仪上，绿色的生命线有节奏地跳动，每一声都像是在说："我在这里，你很安全。"**

### 核心价值
- **温暖** - 不是冰冷的专业感，而是亲切的关怀
- **可靠** - 像心跳一样有节奏、稳定
- **安全感** - 让独居用户感到"有人关心我"

## 3. 字体系统

### 字体选择
```
中文字体: Noto Sans SC (思源黑体)
- 理由：清晰易读，亲和力强，适合日常场景
```

### 字体层级
```
Display (品牌): 40px, Bold - 仅在首页 Logo 使用
H1 (标题): 28px, Bold - 页面标题
H2 (副标题): 24px, Medium - 卡片标题
H3 (三级标题): 20px, Medium - 小标题
Title (主标题): 18px, Bold - 卡片标题
Body (正文): 16px, Regular - 主要文字
Body Medium: 16px, Medium - 强调文字
Small (小字): 14px, Regular - 辅助文字
Small Medium: 14px, Medium - 强调小字
Caption (说明): 12px, Regular - 标签、按钮文字
Caption Medium: 12px, Medium - 强调标签
```

### 排版规则
- **行高**：1.6倍（舒适阅读）
- **字间距**：正文 0，大标题 -0.02em
- **对齐**：左对齐（自然的阅读习惯）

## 7. 动效系统

### 动画时长
```
快速: 200ms - 按钮反馈
正常: 300ms - 页面切换
缓慢: 500ms - 页面加载动画
极慢: 800ms - 复杂动画
```

### 缓动曲线
```
easeIn - 进入动画
easeOut - 退出动画
easeInOut - 双向动画
spring - 弹簧效果
bounce - 弹跳效果
```

### 常用动画效果

#### 1. 页面加载动画（淡入 + 滑入）
```javascript
Animated.parallel([
  Animated.timing(fadeAnim, {
    toValue: 1,
    duration: 500,
    easing: 'ease-out',
  }),
  Animated.timing(slideAnim, {
    toValue: 0,
    duration: 500,
    easing: 'ease-out',
  }),
]).start();
```

#### 2. 按钮按压动画（缩放）
```javascript
onPressIn: () => {
  Animated.spring(scaleAnim, {
    toValue: 0.95,
    useNativeDriver: true,
  }).start();
},
onPressOut: () => {
  Animated.spring(scaleAnim, {
    toValue: 1,
    useNativeDriver: true,
  }).start();
},
```

#### 3. 脉动动画（心跳效果）
```javascript
const pulseAnimation = Animated.loop(
  Animated.sequence([
    Animated.timing(pulseAnim, {
      toValue: 1.1,
      duration: 1000,
      useNativeDriver: true,
    }),
    Animated.timing(pulseAnim, {
      toValue: 1,
      duration: 1000,
      useNativeDriver: true,
    }),
  ])
);
pulseAnimation.start();
```

#### 4. 抖动动画（警告效果）
```javascript
Animated.sequence([
  Animated.timing(shakeAnim, { toValue: 10, duration: 50, useNativeDriver: true }),
  Animated.timing(shakeAnim, { toValue: -10, duration: 50, useNativeDriver: true }),
  Animated.timing(shakeAnim, { toValue: 5, duration: 50, useNativeDriver: true }),
  Animated.timing(shakeAnim, { toValue: -5, duration: 50, useNativeDriver: true }),
  Animated.timing(shakeAnim, { toValue: 0, duration: 50, useNativeDriver: true }),
]).start();
```

## 10. 设计禁忌 ❌

### 不要做的
1. ❌ 医疗蓝 + 白色卡片 - 太冷冰冰
2. ❌ 尖锐的边角 - 会让人紧张
3. ❌ 密集的信息 - 独居用户需要简洁
4. ❌ 快节奏的动画 - 会让人焦虑
5. ❌ 刺眼的红色 - 错误提示用柔和的红
6. ❌ 过多的弹窗 - 减少干扰
7. ❌ 冰冷的医疗图标 - 用生活化的图标
8. ❌ 黑色阴影 - 用橙色阴影保持温暖感

### 要做的
1. ✅ 暖色调主色 - 给人安全感
2. ✅ 圆润的边角 - 亲和力强
3. ✅ 充足的留白 - 呼吸感
4. ✅ 缓慢的动画 - 让人安心
5. ✅ 柔和的功能色 - 不刺眼
6. ✅ 清晰的反馈 - 每个操作都有回应
7. ✅ 生活化的语言 - "您好" 不是 "用户 ID: 12345"
8. ✅ 橙色阴影 - 保持温暖感

## 13. 总结

这个设计方案的核心是**"温暖的守护"**：

- **颜色**：晨光橙（温暖）+ 生命绿（安全）
- **形状**：圆润（亲和）+ 留白（呼吸）
- **动画**：舒缓（安心）+ 脉动（生命力）
- **语言**：亲切（陪伴）不是专业（冰冷）

这个设计让独居用户在使用时感受到**"有人关心我"**，而不是**"我被监控"**。
