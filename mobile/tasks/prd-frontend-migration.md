# 前端迁移 PRD - 从 Flutter 到 Expo + React Native

## 引言/概述

本 PRD 定义了将"起了吗 App"前端从 Flutter 迁移到 Expo 54 + React Native 的完整计划。迁移工作需要保留所有核心功能，同时应用"温暖守护"设计风格和 UI/UX Pro Max 优化标准。

**问题陈述**：
- 当前 Flutter 前端包含 19 个页面
- 已迁移 4 个核心页面（登录、注册、首页、SOS）
- 剩余 15 个页面需要迁移
- 需要保持与后端 API 的完全兼容

## 目标

- [ ] 将所有 Flutter 页面迁移到 Expo + React Native
- [ ] 应用"温暖守护"设计风格（晨光橙 + 生命绿）
- [ ] 遵循 UI/UX Pro Max 优化标准
- [ ] 保持与后端 API 的完全兼容
- [ ] 通过 TypeScript 编译和 ESLint 检查
- [ ] 所有页面支持无障碍功能（WCAG 2.1 AA）

## 功能需求

### 通用需求
1. 所有页面使用 `Screen` 组件包裹
2. 所有页面使用主题驱动的样式（`theme-warm.ts`）
3. 所有交互元素使用 `Pressable` 替代 `TouchableOpacity`
4. 所有交互元素添加无障碍属性（`accessibilityLabel`, `accessibilityHint`, `accessibilityRole`）
5. 所有触摸区域添加 `hitSlop`（最小 12px）
6. 所有触摸反馈使用 Android ripple + iOS opacity
7. 所有页面支持暗色/亮色主题切换
8. 所有页面遵循"温暖守护"设计风格

## 设计考虑

### UI/UX 设计
- 使用"温暖守护"设计风格（晨光橙 #FF8A65 + 生命绿 #66BB6A）
- 遵循 UI/UX Pro Max 优化标准
- 所有圆角 8-32px
- 所有间距 16-64px
- 所有阴影使用橙色（rgba(255, 138, 101, 0.12)）
- 所有动画时长 150-500ms

### 可复用组件
- `Screen` - 页面容器
- `ThemedText` - 主题化文本
- `ThemedView` - 主题化视图
- `Input` - 输入框组件
- `Button` - 按钮组件
- `Card` - 卡片组件
- `ListItem` - 列表项组件
- `Modal` - 模态框组件

### 架构决策
- 使用 Expo Router 进行路由管理
- 使用 React Context 进行状态管理（AuthContext）
- 使用 API Client 封装网络请求
- 使用 AsyncStorage 进行本地存储
- 使用 @react-native-async-storage/async-storage

### 主题系统
- 主题配置：`constants/theme-warm.ts`
- 主题钩子：`hooks/useTheme.ts`
- 支持暗色/亮色主题切换
- 支持跟随系统主题

## 技术考虑

### 技术栈
- 前端框架：Expo 54 + React Native
- 语言：TypeScript
- UI 库：无（使用原生组件）
- 路由：Expo Router
- 状态管理：React Context
- 网络请求：Fetch API + API Client
- 本地存储：@react-native-async-storage/async-storage
- 动画：react-native-reanimated
- 图标：@expo/vector-icons

### 约束条件
- 必须使用 Expo SDK 54
- 必须兼容 Android + iOS + Web
- 必须使用 TypeScript
- 必须通过 ESLint 检查
- 必须通过 TypeScript 编译
- 必须支持无障碍功能（WCAG 2.1 AA）

### 依赖项
- expo-router：路由管理
- expo-linear-gradient：渐变效果
- expo-status-bar：状态栏
- @expo/vector-icons：图标库
- @react-native-async-storage/async-storage：本地存储
- react-native-safe-area-context：安全区域
- react-native-gesture-handler：手势处理

### 性能需求
- 所有动画使用 `useNativeDriver: true`
- 长列表使用 FlatList
- 图片使用 expo-image 优化加载
- 避免不必要的重渲染
