# 起了吗 App 项目重构 PRD

## 1. 引言

### 1.1 背景
"起了吗 App"是一个面向独居人群的紧急医疗服务应用，当前项目包含：
- Backend: 基于 FastAPI 的后端服务，已基本完成
- Mobile Client: 基于 Expo 54 + React Native 的移动端，从 Flutter 迁移而来，核心功能尚未完成
- Frontend: 旧的 Flutter 项目，已废弃

### 1.2 重构目标
1. **清理废弃代码**: 移除旧的 Flutter frontend
2. **完善移动端功能**: 完成所有核心功能页面的开发和测试
3. **优化代码质量**: 统一代码风格，提升可维护性
4. **完善文档**: 更新 API 文档、部署文档、开发文档

### 1.3 项目愿景
为独居人群提供全方位的紧急医疗救援服务，实现从"被动通知"到"主动救援"的质变。

## 2. 目标

### 2.1 业务目标
- 提供稳定可靠的签到监测功能
- 实现快速响应的 SOS 紧急求助机制
- 提供全面的健康档案管理功能
- 实现智能预警和多方联动

### 2.2 技术目标
- 移动端测试覆盖率达到 70% 以上
- 后端测试覆盖率达到 60% 以上
- API 响应时间 < 500ms（P95）
- 应用启动时间 < 3秒

## 4. 需求

### 4.1 功能需求
#### 4.1.1 签到功能
- 用户可以每天完成签到
- 支持自动签到（基于位置或设备）
- 显示签到历史和统计
- 连续未签到触发预警

#### 4.1.2 SOS 功能
- 一键发送求助信号
- 自动获取 GPS 位置
- 向联系人和急救中心发送通知
- 实时显示救援状态

#### 4.1.3 联系人管理
- 添加/编辑/删除紧急联系人
- 设置通知优先级和渠道
- 支持多种联系方式（电话、短信、APP）

#### 4.1.4 健康档案
- 记录病史、用药、过敏史
- 支持快速分享给急救中心
- 数据加密存储

#### 4.1.5 设备管理
- 绑定智能设备（手环、手表）
- 实时监测生理数据
- 异常数据自动预警

#### 4.1.6 知识库
- 提供急救知识和健康资讯
- 支持分类浏览和搜索
- 离线缓存常用文章

### 4.2 非功能需求
#### 4.2.1 性能要求
- API 响应时间 < 500ms（P95）
- 应用启动时间 < 3秒
- 页面切换流畅（60fps）

#### 4.2.2 可靠性要求
- 系统可用性 > 99.9%
- 数据持久化保证
- 异常恢复机制

#### 4.2.3 安全性要求
- 用户数据加密存储
- API 访问权限控制
- 防止 SQL 注入和 XSS 攻击

#### 4.2.4 可维护性要求
- 代码注释完整
- 测试覆盖率 > 70%
- 文档清晰完整

## 6. 设计和技术考虑

### 6.1 架构设计
```
┌─────────────────────────────────────────┐
│      Mobile Client (Expo 54)            │
│  - React Native 0.81.5                  │
│  - Expo Router 6.0                      │
│  - React Context (State Management)     │
└─────────────────────────────────────────┘
                    ↓ HTTPS
┌─────────────────────────────────────────┐
│      Backend API (FastAPI)              │
│  - Python 3.12                         │
│  - SQLAlchemy 2.0                      │
│  - Redis 7.0                           │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│      Database Layer                     │
│  - PostgreSQL 15                       │
│  - Redis Cache                         │
└─────────────────────────────────────────┘
```

### 6.2 技术栈选择
#### 前端
- **框架**: Expo 54 + React Native 0.81.5
- **路由**: Expo Router 6.0
- **状态管理**: React Context
- **UI 组件**: React Native 组件 + Expo 模块
- **网络**: fetch API
- **本地存储**: AsyncStorage

#### 后端
- **框架**: FastAPI 0.104.1
- **数据库**: PostgreSQL 15 + SQLAlchemy 2.0
- **缓存**: Redis 7.0
- **认证**: JWT + OAuth2.0
- **测试**: pytest 7.4.3

### 6.3 数据流设计
```
UI Component
    ↓ (User Action)
Service Layer
    ↓ (API Call)
API Client
    ↓ (HTTP Request)
Backend API
    ↓ (Database Query)
Database
```

### 6.4 安全考虑
- HTTPS 通信加密
- JWT Token 认证
- 敏感数据加密存储（AES-256）
- API 速率限制
- SQL 注入防护
