# Phase 2 扩展功能 PRD

## 1. 概述

Phase 2 目标：扩展智能设备、急救资源、知识库、用药提醒功能，提升应用实用性。

## 2. 目标

1. 实现智能设备绑定和实时数据显示
2. 实现急救资源（AED、医院）地图和列表
3. 实现急救知识库分类浏览
4. 实现用药提醒功能

## 3. 用户故事

### US-001: 创建设备列表页面
**描述**: 作为用户，我能够查看已绑定的智能设备列表。

**验收标准**:
- [ ] 显示设备列表（设备名称、类型、连接状态、电量）
- [ ] 支持下拉刷新
- [ ] 空状态提示（暂无设备）
- [ ] 添加设备按钮

### US-002: 实现设备绑定功能
**描述**: 作为用户，我能够绑定新的智能设备。

**验收标准**:
- [ ] 扫描附近的蓝牙设备
- [ ] 显示可绑定设备列表
- [ ] 点击绑定设备
- [ ] 显示绑定成功/失败提示

### US-003: 实现设备解绑功能
**描述**: 作为用户，我能够解绑已连接的设备。

**验收标准**:
- [ ] 设备卡片上显示解绑按钮
- [ ] 解绑前显示确认对话框
- [ ] 解绑成功后刷新列表

### US-004: 创建设备数据页面
**描述**: 作为用户，我能够查看设备的实时数据。

**验收标准**:
- [ ] 显示设备实时数据（心率、步数、血压等）
- [ ] 数据图表展示（趋势图）
- [ ] 显示最后更新时间
- [ ] 支持下拉刷新数据

### US-005: 创建 AED 地图页面
**描述**: 作为用户，我能够在地图上查看附近的 AED 设备。

**验收标准**:
- [ ] 显示地图（高德地图）
- [ ] 显示当前位置
- [ ] 显示附近 AED 设备标记
- [ ] 点击标记显示设备详情

### US-006: 创建医院列表页面
**描述**: 作为用户，我能够查看附近的医院列表。

**验收标准**:
- [ ] 显示医院列表（名称、地址、距离、电话）
- [ ] 按距离排序
- [ ] 支持下拉刷新
- [ ] 点击可导航/拨打电话

### US-007: 创建急救知识分类页面
**描述**: 作为用户，我能够浏览急救知识分类。

**验收标准**:
- [ ] 显示知识分类（CPR、AED、止血、骨折等）
- [ ] 分类卡片设计
- [ ] 点击分类进入文章列表

### US-008: 创建文章列表页面
**描述**: 作为用户，我能够查看分类下的文章列表。

**验收标准**:
- [ ] 显示文章列表（标题、摘要、封面图）
- [ ] 支持下拉刷新和上拉加载
- [ ] 点击文章进入详情

### US-009: 创建文章详情页面
**描述**: 作为用户，我能够阅读急救知识文章。

**验收标准**:
- [ ] 显示文章标题、内容、图片
- [ ] 支持步骤说明展示
- [ ] 收藏/分享功能（可选）

### US-010: 创建用药提醒列表页面
**描述**: 作为用户，我能够查看我的用药提醒计划。

**验收标准**:
- [ ] 显示用药计划列表（药品名称、时间、剂量）
- [ ] 区分今日用药和全部用药
- [ ] 标记已服用/未服用状态
- [ ] 添加用药计划按钮

### US-011: 实现添加用药提醒功能
**描述**: 作为用户，我能够添加新的用药提醒。

**验收标准**:
- [ ] 选择药品（从健康档案用药列表）
- [ ] 设置用药时间
- [ ] 设置用药频率（每天/每周/自定义）
- [ ] 设置剂量
- [ ] 保存提醒计划

### US-012: 实现用药提醒通知
**描述**: 作为用户，我能够在用药时间收到提醒通知。

**验收标准**:
- [ ] 本地推送通知
- [ ] 通知显示药品名称和剂量
- [ ] 点击通知进入应用
- [ ] 标记已服用

## 4. 非目标

- 不实现蓝牙设备实时数据同步（使用模拟数据）
- 不实现地图导航功能（仅显示位置）
- 不实现文章搜索功能
- 不实现用药历史统计

## 5. 技术考虑

### 依赖
- `amap_flutter_map` - 高德地图
- `flutter_blue_plus` - 蓝牙设备（已添加）
- `flutter_local_notifications` - 本地通知（已添加）
- `fl_chart` - 图表展示（已添加）

### API 端点
- GET `/api/v1/devices` - 获取设备列表
- POST `/api/v1/devices` - 绑定设备
- DELETE `/api/v1/devices/{id}` - 解绑设备
- GET `/api/v1/aed` - 获取 AED 列表
- GET `/api/v1/emergency-centers` - 获取医院列表
- GET `/api/v1/knowledge` - 获取知识分类
- GET `/api/v1/knowledge/{category_id}/articles` - 获取文章列表
- GET `/api/v1/knowledge/articles/{article_id}` - 获取文章详情
- GET `/api/v1/medications` - 获取药品列表
- POST `/api/v1/medications/{id}/reminders` - 设置提醒
