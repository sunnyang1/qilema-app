# 架构文档

## 系统架构

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   移动端     │────▶│   Nginx     │────▶│  Backend    │
│  (React     │     │  (反向代理)  │     │  (FastAPI)  │
│   Native)   │◀────│             │◀────│             │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                                │
                       ┌─────────────┐         │
                       │   Redis     │◀────────┤
                       │   (缓存)    │         │
                       └─────────────┘         │
                                               │
                       ┌─────────────┐         │
                       │  PostgreSQL │◀────────┘
                       │   (数据库)   │
                       └─────────────┘
```

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React Native |
| 后端 | Python FastAPI |
| 数据库 | PostgreSQL |
| 缓存 | Redis |
| 反向代理 | Nginx |
| 部署 | Docker, GitHub Actions |
