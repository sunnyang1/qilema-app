## 优先级分级

- [ ] **P0**：需要立即移除（安全风险、重大成本、阻塞其他工作）
- [ ] **P1**：当前冲刺中移除
- [ ] **P2**：积压工作 / 下一次迭代

---

## 安全立即删除

### 项目：[名称/描述]

| 字段 | 详情 |
|------|------|
| **位置** | `path/to/file.ts:line` |
| **理由** | 为什么应该移除此内容 |
| **证据** | 未使用（无引用）、死功能标志、已弃用的 API |
| **影响** | 无 / 低 - 没有活跃消费者 |
| **删除步骤** | 1. 移除代码 2. 移除测试 3. 移除配置 |
| **验证** | 运行测试、检查无运行时错误、监控日志 |

## 延迟删除（需要计划）

### 项目：[名称/描述]

| 字段 | 详情 |
|------|------|
| **位置** | `path/to/file.ts:line` |
| **为什么延迟** | 活跃消费者、需要迁移、利益相关者签署 |
| **前置条件** | 功能标志关闭 2 周、遥测显示 0 使用 |
| **破坏性更改** | 列出任何 API/契约更改 |
| **迁移计划** | 消费者迁移的步骤 |
| **时间表** | 目标日期或冲刺 |
| **所有者** | 负责的人/团队 |
| **验证** | 确认安全删除的指标（错误率、使用计数） |
| **回滚计划** | 如果发现问题如何恢复 |

---

## 删除前检查清单

- [ ] 搜索代码库中的所有引用（`rg`、`grep`）
- [ ] 检查动态/反射用法
- [ ] 验证无外部消费者（API、SDK、文档）
- [ ] 审查功能标志遥测（如适用）
- [ ] 更新/移除测试
- [ ] 更新文档
- [ ] 通知团队（如果是共享代码）
